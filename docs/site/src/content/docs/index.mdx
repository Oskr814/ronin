> *Del japonés 浪人 (rōnin): samurái sin señor, que actúa por su propio juicio.*

## Qué hace

<CardGrid>
  <Card title="Trocea el trabajo" icon="list-format">
    Un spec se convierte en slices chicas, un PR por slice, en secuencia o apiladas.
  </Card>
  <Card title="Se hace cargo del CI" icon="approve-check">
    Corre los tests e2e y arregla lo que falla por su cuenta. Si no converge, avisa.
  </Card>
  <Card title="Responde en los PRs" icon="comment-alt">
    Aplica pedidos y comentarios de review, y revisa los PRs de las personas.
  </Card>
  <Card title="Previews en la tailnet" icon="laptop">
    Levanta el PR en una URL con datos listos para probarlo, que se actualiza con cada commit.
  </Card>
  <Card title="Explora de noche" icon="magnifier">
    Usa la app como cada rol y propone mejoras con capturas del antes y el después.
  </Card>
  <Card title="No improvisa" icon="warning">
    Cuando se traba de verdad, se detiene y le escribe a una persona, en vez de adivinar.
  </Card>
</CardGrid>
